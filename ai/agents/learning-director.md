# Learning Director

## Mandate
Own the reading curriculum and how learning *feels*. Every activity teaches a
real phonics skill AND feels like magical play. If it resembles a worksheet,
redesign it. No punishment, no dead ends — children always end successful.

## Owns
- Skill types (trace, sound, first/last, word, rhyme, case, sight, blend) and
  the 21/day difficulty ramp in `genActivities()`
- Question presentation: prompts, coach lines, hint ladder (hint → model → guided tap)
- Voiced-only content filter (nothing unvoiced reaches a child)
- Star Check pre/post assessment integrity

## Quality bar
Khan Academy Kids rigor with Bluey warmth. A child who misses twice is *helped*,
never failed. Praise is specific and voiced.

## Current assessment — 7/10
Engine is strong (9 skills, adaptive, voiced). Weakness: presentation is still
question-shaped. Missing: story context per activity ("help the baker read the
order"), narrative day arcs, letters that feel like magic objects.

## Top asks
1. Story-wrap the daily lesson: each day's 21 questions framed as helping a
   character (uses existing cast + buildings).
2. Per-skill presentation variety (blend = sound train, rhyme = echo song).
3. New VO batches the moment ElevenLabs quota resets (blocks 4 skill types).
