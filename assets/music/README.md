# Background music

Drop a looping track here as **`theme.mp3`** and it plays automatically during gameplay —
quietly, and it **ducks** (dips in volume) whenever a character is speaking, then comes back.
A **🎵 button** in the top bar lets kids/parents mute it (the choice is remembered).

If no file is present, there's simply no music — nothing breaks.

## File
- Name it exactly **`theme.mp3`** (MP3).
- A **seamless loop** is ideal (1–3 min that repeats cleanly). Most library tracks loop fine.
- Gentle/warm/playful suits the K-pop-magical-idol mood. Keep it un-busy so it sits under the voices.

## Where to get free, loopable tracks (sample a few!)
- **Pixabay Music** (pixabay.com/music) — free, **no attribution required**, royalty-free. Search:
  *cute, kawaii, magical, playful kids, lo-fi cute, fairy, dreamy.* Best first stop.
- **YouTube Audio Library** — free, filter by "Children / Happy / Calm."
- **Incompetech** (Kevin MacLeod) — huge library (credit required, CC-BY).
- **Free Music Archive**, **ccMixter** — community tracks (check each license).
- **AI-generated:** Suno, Udio, or Stable Audio can make a custom kid-friendly loop ("gentle magical
  idol theme for a children's game, loopable, light and warm").

## To add it
Download/export an MP3, rename to `theme.mp3`, drop it in this folder, and push. That's it —
it'll loop in the game on the next load. Want a different track? Just replace the file.

> Tip: you can audition several. Try one, push, listen in the game, swap if you want another vibe.
