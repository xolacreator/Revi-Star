# Learning Engine & Voice Pipeline (reference)

## Skill types (8) — all in `a1.js`
Item builders (`itTrace`, `itSound`, `itFirst`, `itLast`, `itWord`, `itRhyme`, `itCase`, `itBlend`) draw from content banks and are assembled by `genActivities(day, N)`:

| Template | Skill | Bank |
|---|---|---|
| `trace` | finger-trace a letter | `TRBANK` (S C M N L T) |
| `soundMatch` | which letter says *sss* | `LETTERBANK` (18) |
| `firstSound` | what does *bee* start with | `LETTERBANK` words |
| `lastSound` | what does *cat* end with | `LASTWORDS` (CVC, non-x endings) |
| `wordPicture` | which word says *cat* | `SIGHTBANK` (22) |
| `rhyme` | what rhymes with *cat* | `RHYMEBANK` (20) |
| `caseMatch` | find the little **b** for **B** | `LETTERBANK` |
| `blend` | tap the sounds: c-a-t | `CVCWORDS` (49) |

- **Questions per day:** `QUESTIONS_PER_DAY = 21` (one constant; change it to shorten/lengthen sessions).
- **Distribution:** ~16/16/12/10/14/12/10% across categories, remainder → blend; **interleaved** round-robin for variety; **offset indexing** (`pickN`) varies items day to day.
- **Days 1–3** are hand-authored story beats, then **padded** up to `QUESTIONS_PER_DAY` with generated practice (`getDay`).
- Adding content = append to a bank in `a1.js` **and** mirror it in `tools/voice/build-lines.mjs`, then regenerate voices.

## Voice pipeline
- Lines live in `tools/voice/lines.json`, generated by `node tools/voice/build-lines.mjs` (keeps the banks + templates in sync with the game).
- Clips render via the **Generate Voiceover** GitHub Action → `tools/voice/generate.mjs` (ElevenLabs, premade voices) → `assets/vo/<id>.mp3` + `manifest.json`.
- The generator **skips clips that already exist** (only fills gaps; `VO_FORCE=1` to re-render) — so re-running a batch (or `all`) is cheap.
- In-game, `say(text,{id,char})` plays the clip if present, else stays silent (device TTS is off). Text→id mapping is built in `a1.js` from the same templates.

### Voice batches (run from the Actions tab)
`core · tut · letters · words · blend · rhyme · case · last · check · extra` (or `all`).
After adding bank content, run `blend`, `rhyme`, `case`, `last` (or just `all`) to voice the new prompts. `extra` covers greetings/teases/transformation lines.
