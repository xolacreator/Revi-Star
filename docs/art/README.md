# Art — Source of Truth

Drop the **HUNTRIX concept sheet** here as `concept-sheet.png` (the Rumi / Mira / Zoey
character sheet). It is the **visual foundation** for the entire project:
clean silhouettes, bold color, expressive anime faces, mobile-optimized, animation-ready.

## Adaptation notes for ages 5–7
- Keep the look, **soften** it: rounder silhouettes, slightly larger eyes, friendlier proportions.
- Reframe every "weapon" as a clearly-**friendly light tool** (Songstaff, Starlight Blade that
  draws glowing paths, Beat Stars that make music) — never used to harm.
- Three new heroes need concept art in the same style: **Nova** (Math, sky-blue/gold, stars),
  **Indie** (Creativity, rainbow pastels, paint), **Remi** (Memory, teal/lavender, owl motif).
  Art briefs are in `../character-bible-little-legends.md`.
